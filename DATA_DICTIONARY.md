# Data Dictionary

## Raw Data (`data/raw/`)

### `customers.csv`
- `customer_id`: Unique identifier
- `country`: Country of origin
- `industry`: Business sector
- `company_size`: Number of employees
- `acquisition_channel`: Marketing channel

### `subscriptions.csv`
- `customer_id`: Link to customers
- `plan_type`: Starter, Professional, Enterprise
- `contract_type`: Month-to-Month, Annual, 2-Year
- `tenure_months`: Months since signup
- `annual_revenue`: Computed ARR in USD
- `auto_renew`: True/False

### `product_usage.csv`
- `customer_id`: Link to customers
- `login_frequency`: Logins per month
- `usage_change_30d`: % change in usage over last 30 days
- `usage_change_90d`: % change in usage over last 90 days

### `support_tickets.csv`
- `customer_id`: Link to customers
- `support_tickets_30d`: Volume in last 30 days
- `open_tickets`: Currently unresolved tickets
- `avg_resolution_hours`: Time to close tickets
- `escalation_count`: Number of times an issue was escalated

### `churn_labels.csv`
- `customer_id`: Link to customers
- `churn_probability_ground_truth`: Latent probability generated by the synthetic script
- `churned`: Target variable (1 = Churned within 30 days, 0 = Retained)

## Processed Data (`data/processed/`)
- `master_data.csv`: Joined and cleaned table.
- `master_data_segmented.csv`: Master data with `segment_id` and `segment_name` from KMeans clustering.
